# Solved Problems 🧩

A collection of solved programming problems in JavaScript.
I solve 2–3 problems a day to keep my JS skills sharp, improve my
algorithmic thinking, and prepare for technical interviews.

## 📁 Structure

Each problem lives in its own folder:

```
001-task-name/
├── README.md      ← problem statement, approach, and complexity
└── solution.js    ← solution with JSDoc comments
```

## 🛠️ Tech

- JavaScript (Node.js)

## 🌐 Platforms

- [LeetCode](https://leetcode.com/)
- [HackerRank](https://www.hackerrank.com/)

## ▶️ Running a solution

```bash
node 001-task-name/solution.js
```
